# crypto-protocols

Программы по криптографии.

## Запуск

```
cargo run --bin euclid    # обобщённый алгоритм Евклида
cargo run --bin inverse   # инверсия по модулю
cargo run --bin dh        # система Диффи–Хеллмана (лабораторная 2.20)
cargo run --bin shamir    # шифр Шамира (лабораторная 2.21)
cargo run --bin rsa       # шифр RSA (лабораторная 2.23)
cargo run --bin poker     # ментальный покер (лабораторная 5.3)
```

Программы спрашивают числа с клавиатуры.

В `dh`, `shamir` и `poker` параметры и ключи можно не вводить, а нажать Enter: тогда p = 30803, g = 2, а ключи выбираются случайно. Сообщение в `shamir` вводится всегда.

В `rsa` по Enter берутся значения из задания 2.23: P_A = 131, Q_A = 227, P_B = 113, Q_B = 281, d_A = d_B = 3. Получатель (A или B) и сообщение вводятся всегда.
